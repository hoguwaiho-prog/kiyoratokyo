# 使い方（Kawaii 集客調査キット）

## はじめに
1. このフォルダをPCの好きな場所に置く
2. ターミナルでこのフォルダに移動して `claude` を起動
3. `/setup` を実行

## コマンドと、あなたが用意するもの

| コマンド | やること | 用意するもの |
|---|---|---|
| `/review-count` | 両店の口コミ総数と評価をAPIで取得し、週1で記録 | Google Places API のキー（`.env` に記入） |
| `/review-analyze` | 口コミの言語比率と「選んだ理由」を集計 | 両店の口コミ直近100件のコピー（`data/reviews_raw/` に店ごとに保存） |
| `/site-audit` | 自社英語ページが検索の入口になっているかを診断し、競合と比較 | なし |
| `/queue-count` | カメラから行列の長さを曜日×時間帯で集計 | カメラのCSV、または5分おきの静止画（`data/camera/` に保存） |
| `/daily-setup` | 口コミ数・行列・マップ表示回数・HPアクセスなどを毎日自動で記録し、推移グラフを出せるようにする | 使うAPIの権限（無いものは保留でOK）、PCが毎日起動している時刻 |
| `/report` | 全部まとめてコンテスト用の根拠資料に | 自社の欠品記録（通貨別・月別の回数） |

## おすすめの順番
1. `/site-audit`（用意するものがなく、すぐ結果が出る）
2. `/review-analyze`（口コミのコピーだけで仮説の当たりがつく）
3. `/daily-setup`（毎日の自動記録。早く始めるほど施策前のデータがたまる。口コミ数だけでも先に始める）
4. `/queue-count`（カメラの確認が済んだら。過去分の集計用）
5. `/report`

施策を入れた日は `data/daily/events.csv` に「日付, 内容」を1行書いてください。グラフに印が付き、前後の比較ができます。

## 守っていること
Googleマップや検索画面の自動読み取りはしない／カメラ映像は社外に出さない・属性推定しない／外に影響する操作は必ず確認してから、などのルールは `CLAUDE.md` に書いてあり、Claude Code が自動で読み込みます。
