# サイト診断：英語ページは「検索の入口」になっているか

- 取得日：2026-11-18（日本時間。UTCでは2026-11-17）
- 対象：自社 https://www.kawaiimoneyexchange.com/ ／ 競合 インターバンク https://www.interbank.co.jp/ninja/ ／ ドルレンジャー新宿西口 https://d-ranger.jp/en/shop/shinjuku/
- 方法：サーバーが返すHTML（JS実行前）を各ページ1回ずつ取得し、Playwright（ヘッドレスChromium）で英語切り替え・シミュレーター・予約フォームを操作（予約フォームは送信していない）。3サイトとも robots.txt でアクセスが許可されていることを確認済み。

---

## 結論
1. **Kawaiiの英語版は、検索エンジンからはほぼ見えません。** 「English」ボタンはブラウザ内（localStorage）で表示を切り替えるだけです。URLは変わらず、サーバーから返るHTMLもtitle・descriptionも日本語のままです。英語ページとして登録される入口がありません。
2. **競合2社は、英語ページに独立したURLがあります。** インターバンクは `/ninja/` に加え、`/ninja_sc/`（簡体字）と `/ninja_tc/`（繁体字）も持っています。どれもHTMLの時点で英語（中国語）の本文が入っていて、インターバンクはsitemapにも登録しています。「英語で検索した人の入口」の差は、技術的にはここで生まれていると考えられます。
3. **店頭の安心材料もWebでは負けています。** ドルレンジャーは**在庫（SOLD OUT）と分単位の更新時刻**を、インターバンクは**全通貨「手数料込み」**を英語で明記しています。Kawaiiはどちらもありません。一方で、Kawaiiの英語シミュレーターと予約フォームは英語で最後まで使え、使い勝手では負けていません。**直すべきは「見つけてもらう入口」と「来店前の安心材料の明示」です。**

### その他に見つかった問題（自社）
- **sitemap に載っている `/about` が 404**（「This page could not be found」）です。Googleに壊れたURLを案内している状態です。
- **sitemap と og:url が `kawaiimoneyexchange.com`（wwwなし）で、実際のサイトは `www.` です。** canonical タグもありません。
- **`<html lang="en">` なのに本文は日本語**で、言語の判定を誤らせる可能性があります。
- **「当店の特徴」ページの不一致**：meta description は「選ばれる5つの理由」なのに、本文は「3 reasons」です。
- **お客様の声に出典（Google口コミ等）・日付がありません。**「怪しい」という印象を持つ人には、作った文章に見えるおそれがあります。
- オンライン両替は「Coming Soon」のままです。

## 注意点
- 競合ページが実際に何位に表示されているかは、今回は調べていません（Google検索画面の自動取得は規約上しないため）。「米国からの検索でインターバンク英語ページが上位、Kawaiiは非表示」は、2026-11-17 に手作業で確認された情報です。
- Googlebot はJSを実行しますが、ボタンを押したりlocalStorageを保持したりはしません。そのため、現在の作りでは英語版はインデックスされない可能性が高いと判断しています。確定させるには Search Console の「URL検査」で英語テキストが登録されているかを見る必要があります。
- ドルレンジャーの英語ページは WordPress マルチサイト（`/en/`）です。英語用のsitemapが別にある可能性があります（今回はメインのsitemapのみ確認）。
- 予約フォームは確認画面の手前までしか確認していません（送信は一切していません）。

## Search Console を使っている場合の確認方法
1. **国別の表示回数**：「検索パフォーマンス」→「国」タブ。米国・英国・豪州などの表示回数とクリック数を見る。
2. **英語の検索キーワード**：同じ画面の「クエリ」タブで、フィルタ「クエリ → 次を含む」に `exchange` `currency` `shinjuku` などを入れる。
3. **英語版が登録されているか**：「URL検査」にトップURLを入れ、「クロール済みページを表示」→ HTML に英語本文があるかを見る。今の作りでは日本語だけになっているはずです。
4. 修正後は「URL検査」で `/en/` を「インデックス登録をリクエスト」し、sitemap を再送信します。
