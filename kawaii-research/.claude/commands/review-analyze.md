手でコピーした口コミテキストを分析してください。

## 入力
`data/reviews_raw/` のテキストファイル。ファイル名で店を区別する（例：`interbank.txt`, `kawaii.txt`）。
ファイルが無ければ、ユーザーに次の手順を案内して止まる：
- Googleマップで店を開き、口コミを「新しい順」に並べる
- 直近100件程度を選択してコピーし、店ごとのテキストファイルに貼る
- 外国語の口コミは「原文を表示」にしてからコピーすると言語判定が正確になる（翻訳表示のままなら「Google による翻訳」の表記も一緒にコピーする）

## 処理
1. テキストを口コミ1件ずつに分割する（投稿者名・日付・星の行を手がかりに。うまく分けられない部分はユーザーに見せて確認）。投稿者名は分析に使わず、出力からも除く。
2. 各口コミについて次を判定し、`output/reviews_coded.csv` に保存：
   - store, posted（「2週間前」などの表記そのまま）, stars, language（ja / en / zh / ko / other。翻訳表記があれば原文の言語）
   - 選んだ理由・評価の内容（複数可）：予約 / 在庫・欠品 / 常連・いつも / 行列・人気 / レート・価格 / 速さ / 接客・言語対応 / 立地・分かりやすさ / 信頼・安心 / 怪しい・不安・入りにくい / 待ち時間 / その他
   - 判定はキーワードだけに頼らず文意で行う。迷ったものは `uncertain=true` にする。
3. 集計して `output/reviews_summary.md` に書く：
   - 店ごとの言語比率（外国人客比率の「目安」として。口コミを書く人と来店客は同じではないと注記）
   - 店ごとの理由カテゴリの件数と割合
   - 仮説1〜4（予約・在庫・常連・行列）それぞれを支持する件数
   - Kawaii の「怪しい・不安・入りにくい」系の件数と、その理由の内訳（暖簾・運営者不明・その他）
   - 直近1か月に投稿された件数（「◯日前」「◯週間前」「1か月前」から推定）
   - 代表的な声を各カテゴリ1〜2件、短く要約して添える（投稿者名なし）
4. 結論を3行でまとめる。
