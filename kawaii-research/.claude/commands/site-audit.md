## 自社（https://www.kawaiimoneyexchange.com/）
Playwright と requests で次を確認し、結果を表にする：
1. 言語切り替えで English を選んだときに URL が変わるか（/en などの独立URLがあるか）
2. 英語表示時のページについて、サーバーから返ってくるHTML（JS実行前）に英語の本文が入っているか。JSで後から書き換えているだけなら、検索エンジンには日本語版しか登録されない可能性が高いと説明する
3. `<link rel="alternate" hreflang=...>` の有無
4. 英語表示時の `<title>` と `meta description`
5. sitemap.xml に英語ページが含まれているか
6. レートシミュレーター・予約フォームが英語で最後まで使えるか（途中で日本語に戻らないか）。予約フォームは送信しない
7. 表示されているか確認：手数料込みの明記 / レートの更新時刻 / 在庫状況 / 予約でレートが確定するか / 運営会社名・所在地 / 店内の写真
