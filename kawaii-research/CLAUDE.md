# Kawaii Money Exchange 集客調査プロジェクト

## 背景
- 自社：Kawaii Money Exchange Yokocho（東京都新宿区西新宿1-2-11、思い出横丁）https://www.kawaiimoneyexchange.com/
- 隣の競合：外貨両替のインターバンク / Ninja Money Exchange（西新宿1-2-12）https://www.interbank.co.jp/ 、英語ページ https://www.interbank.co.jp/ninja
- 状況：インターバンクには行列ができるが、隣のKawaiiは「レートで勝っている通貨があっても」選ばれていない。並んでいる人は店頭のレート表を見ていない＝来店前に店を決めている。
- 目的：社内パッチコンテストで「来店前の決め手（在庫・予約・レート・信頼）をオンラインで見える化する」施策を、データ付きで提案する。英語ページの入口化（言語別URL）はその施策の一つ。

## 検証したい仮説（なぜインターバンクに並ぶのか）
1. 予約済みで来ている
2. 在庫が安定している（他店は欠品が多い）
3. いつもの店（常連・習慣）
4. 行列があるから安心（社会的証明）
加えて、自社の課題として「入口に暖簾があり中が見えない」「怪しいという口コミがある」「英語版はあるが独立URLがなく検索の入口になっていない可能性」がある。

## 作業ルール（必ず守る）
- Googleマップ・Google検索の画面をスクレイピングしない（規約違反）。Googleのデータは公式API（Places API、Search Console API、Business Profile API）か、ユーザーが手でコピーしたテキストだけを使う。
- 競合サイトへのアクセスは、公開ページを1回ずつ読む程度にとどめる。robots.txt を守り、連続アクセスしない。
- 防犯カメラの画像・動画はこのPCの中だけで処理し、外部サービスにアップロードしない。人数を数えるだけにして、顔の切り抜きや個人の追跡データは保存しない。
- 映像や口コミから国籍・人種を推定しない。外国人比率は口コミの言語比率を「目安」として使う。
- 口コミの本文を発表資料に載せるときは、短い要約か一部の引用にとどめ、投稿者名は載せない。
- APIキーは `.env` に置き、コードやログに出力しない。`.env` と `data/camera/` は git に入れない。
- 外部への投稿・送信・予約登録など、外に影響することは実行前に必ずユーザーに確認する。
- 定期実行（cron / タスクスケジューラ）の登録は、内容を見せてユーザーの了承を得てから行う。
- 数値はすべて出典と取得日を記録する。推計値（Similarweb等）は「推計」と明記する。

## フォルダ
- `data/review_counts.csv` … 口コミ総数・評価の週次記録
- `data/reviews_raw/` … ユーザーが手でコピーした口コミテキスト（店ごとに1ファイル）
- `data/camera/` … カメラの書き出しCSV、または5分おきの静止画
- `output/` … 集計結果・グラフ・レポート

## 使えるコマンド
`/setup` `/review-count` `/review-analyze` `/site-audit` `/queue-count` `/daily-setup` `/report`
毎日の自動計測は `/daily-setup` で組む。データは `data/daily/` に溜まり、施策を入れた日は `data/daily/events.csv` に記録する。
（各手順は `.claude/commands/` にある）

## 出力の言語
日本語。発表資料にそのまま使えるよう、結論→根拠の数字→注意点の順で書く。
